# Assign a table to a cdm reference.

Assign a table to a cdm reference.

## Usage

``` r
# S3 method for class 'cdm_reference'
cdm[[name]] <- value
```

## Arguments

- cdm:

  A `<cdm_reference>` object.

- name:

  Name where the new table will be assigned.

- value:

  Table with the same source as the `cdm_reference` object.

## Value

The cdm reference.
