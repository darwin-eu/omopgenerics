# Drop a table from a cdm object.

Drop a table from a cdm object.

## Usage

``` r
dropSourceTable(cdm, name)
```

## Arguments

- cdm:

  A `<cdm_reference>` or `<cdm_table>` object.

- name:

  Name(s) of the table(s) to drop. Tidyselect statements are supported.

## Value

The table in the cdm reference.
